# Start11 Tuner

Небольшой редактор настроек Start11, собранный по разбору его бинарников.
Пишет те же значения, что и родное окно Start11, — без взлома и без замены оболочки.

## Как запустить

```powershell
powershell -ExecutionPolicy Bypass -File Start11Tuner.ps1
```

Зависимостей нет: PowerShell 5.1 + WinForms, входит в Windows.

## Что умеет

- **Все настройки, которые Start11 хранит в реестре.** Список контролов строится из фактического содержимого ключа: `0`/`1` → галочка, число → счётчик, строка → поле ввода. Сейчас это 56 ключей, разложенных по разделам (меню, панель задач, закреплённые, поиск, прочее).
- **Пять стилей меню** отдельными карточками, как в родном окне.
- **Фильтр** по имени ключа.
- **Пишет только изменившееся** и перед этим снимает JSON-бэкап в `%LOCALAPPDATA%\Start11Tuner`.
- **Применение без перезагрузки**: пишет значения, пробует закрыть Start11, перезапускает `explorer.exe` и закрывается. Перезагрузка нужна только при смене стиля между Windows 10 и Windows 11 — это требование самого Start11.
- **Откат**: из последнего бэкапа или из списка в разделе «Управление».

## Что выяснилось при разборе

- Настройки Start11 3.x живут в `HKCU\Software\Stardock\Start8\Start8.ini\Start8` (наследие Start8), все значения — строки.
- `C:\Program Files (x86)\Stardock\Start11\sync.dat` — не конфиг, а снимок списка параметров.
- Стили меню по порядку: `Windows 7`, `Modern`, `Windows 10`, `Windows 11`, `Windows App`.
- В `Start11Config.exe` есть предупреждение: смена стиля 10 ↔ 11 требует перезагрузки.
- Запущенный `Start11_64.exe` перезаписывает настройки при выходе. Программно закрыть его нельзя — процесс защищён, `Stop-Process` получает отказ в доступе. Поэтому перед применением лучше выйти из Start11 через его трей.
- `%APPDATA%\Stardock\S10\License.sig` — лицензия. Не читается, не меняется.

## Границы

- Лицензия не трогается: ни активации, ни обхода, ни ключей. Без ключа Start11 не рисует меню — это его поведение, не наше.
- Редактор закреплённых не сделан: они лежат в подключах `Right`/`RightMode` в неразобранном формате.
- Имена ключей показываются как есть (`S11_MaxColour`), без выдуманных подписей: семантика части из них не подтверждена.
