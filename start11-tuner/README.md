# Start11 Tuner

Небольшой конфигуратор Start11, собранный по результатам разбора его бинарников.
Пишет те же значения, что и его собственное окно настроек, — без взлома и без замены оболочки.

## Что выяснилось при разборе

- Настройки Start11 3.x живут в `HKCU\Software\Stardock\Start8\Start8.ini\Start8` (наследие Start8).
- `C:\Program Files (x86)\Stardock\Start11\sync.dat` — не конфиг, а снимок списка параметров.
- Стили меню идут в таком порядке: `Windows 7`, `Modern`, `Windows 10`, `Windows 11`, `Windows App`.
- В самом бинарнике есть предупреждение: смена между стилями Windows 10 и Windows 11 требует перезагрузки.
- Работающий `Start11_64.exe` держит значения в памяти и **перезаписывает `MenuMode` при выходе** — проверено: выставленное вручную `5` превратилось в `6` само.

## Запуск

```powershell
powershell -ExecutionPolicy Bypass -File Start11Tuner.ps1
```

В окне: стиль меню, акрил/размытие, кнопки «Применить» и «Откатить».
Перед первой записью в `%LOCALAPPDATA%\Start11Tuner` кладётся JSON-бэкап всех текущих значений; «Откатить» возвращает последний.

## Границы

- Ничего не активирует и не обходит лицензию. Без ключа Start11 меню не рисует — это его дело, не наше.
- Число для `MenuMode` — гипотеза по порядку стилей в ресурсах. Проверяется одним применением и перезагрузкой; при промахе ставится соседнее.
- Акцент и точные цвета не пишутся: формат цветовых значений не разобран, а угадывать в реестре чужого продукта — плохая идея.
