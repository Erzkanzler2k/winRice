# Start11 Tuner

Редактор настроек Start11, собранный по разбору его бинарников. Пишет те же
значения, что и родное окно Start11, — без взлома и без замены оболочки.

Две реализации:

- **`rs/` — основная, на Rust.** Один exe, никаких зависимостей и внешних
  скриптов: `rs/target/release/start11-tuner.exe` после сборки.
- **`Start11Tuner.ps1` — резервная, на PowerShell + WinForms.** Тот же редактор,
  если Rust-сборки под рукой нет.

## Запуск

Rust:

```powershell
cd rs
cargo build --release
.\target\release\start11-tuner.exe
```

PowerShell:

```powershell
powershell -ExecutionPolicy Bypass -File Start11Tuner.ps1
```

## Что умеет

- **Все настройки, которые Start11 хранит в реестре.** Контролы строятся из
  фактического содержимого ключа: `0`/`1` → галочка, число до 4 цифр → счётчик,
  остальное → поле ввода. Сейчас это 37 значений (56 ключей минус служебные).
- **Человеческие подписи** вместо сырых имён; сам ключ виден в подсказке при
  наведении.
- **Пять стилей меню** отдельными карточками, как в родном окне.
- **Пишет только изменившееся** и перед этим снимает JSON-бэкап в
  `%LOCALAPPDATA%\Start11Tuner`.
- **Применение без перезагрузки**: бэкап → запись изменений → попытка закрыть
  Start11 → перезапуск `explorer.exe` → окно закрывается само. Перезагрузка
  нужна только при смене стиля между Windows 10 и Windows 11 — это требование
  самого Start11.
- **Откат** из последнего бэкапа или из списка в разделе «Управление».

## Что выяснилось при разборе

- Настройки Start11 3.x живут в `HKCU\Software\Stardock\Start8\Start8.ini\Start8`
  (наследие Start8), все значения — строки.
- `C:\Program Files (x86)\Stardock\Start11\sync.dat` — не конфиг, а снимок
  списка параметров.
- Стили меню по порядку: `Windows 7`, `Modern`, `Windows 10`, `Windows 11`,
  `Windows App`.
- В `Start11Config.exe` есть предупреждение: смена стиля 10 ↔ 11 требует
  перезагрузки.
- Запущенный `Start11_64.exe` перезаписывает настройки при выходе. Программно
  закрыть его нельзя — процесс защищён, `taskkill`/`Stop-Process` получают отказ
  в доступе. Поэтому перед применением лучше выйти из Start11 через его трей.
- `%APPDATA%\Stardock\S10\License.sig` — лицензия. Не читается, не меняется.

## Границы

- Лицензия не трогается: ни активации, ни обхода, ни ключей. Без ключа Start11
  не рисует меню — это его поведение, не наше.
- Редактор закреплённых не сделан: они лежат в подключах `Right`/`RightMode`
  в неразобранном формате.
- Цвета показываются числом: семантика части ключей (`S11_MaxColour`,
  `CustomColourV`) не подтверждена, выдумывать ползунки не стал.
- Служебные ключи (лицензия, кэш, флаги первого запуска и миграций) скрыты и не
  пишутся.
